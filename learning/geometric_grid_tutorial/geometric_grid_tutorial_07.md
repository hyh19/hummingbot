## 7.1 比率的动态调整

### 7.1.1 调整触发条件

**ATR% 变化**：
- 如果 ATR% 变化 ±30%，重新计算比率

**交易频率异常**：
- 频率过高：加大比率
- 频率过低：减小比率

### 7.1.2 区间调整

**上涨趋势**：
```
当价格接近上限：
- 上移上限（如 +10%）
- 相应下移下限保持区间宽度
```

**下跌趋势**：
```
当价格接近下限：
- 止损或缩小区间
- 考虑暂停策略
```

## 7.2 资金风险管理

### 7.2.1 上涨时的资金需求

**监控要点**：
- 价格上涨时，高价区需要更多资金
- 预留 20%-30% 备用资金
- 如果资金不足，考虑减少层数

### 7.2.2 止损设置

**区间突破止损**：
- 价格向下突破：止损
- 价格向上大幅突破：止盈

**亏损止损**：
- 设置总资金 -10% 或 -15% 止损

## 7.3 复合网格策略

### 7.3.1 多重网格

在不同时间框架设置不同网格：
- 短期网格：1% 比率，捕捉短期波动
- 中期网格：2% 比率，标准网格
- 长期网格：3% 比率，捕捉大趋势

### 7.3.2 网格组合

```
主力网格：70% 资金，2% 比率
辅助网格：30% 资金，1.5% 比率（密集）
```

## 7.4 本章小结

动态调整要点：
- 根据波动率变化调整比率
- 价格上涨时注意资金需求
- 设置合理的止损止盈
- 可以考虑多重网格策略
