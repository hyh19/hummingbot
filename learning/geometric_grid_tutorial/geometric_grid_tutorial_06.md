## 6.1 案例一：BTC-USDT 等比网格

### 6.1.1 市场分析

**基础信息**：
- 当前价格：50000 USDT
- 市场状态：震荡上行
- 波动率：ATR% ≈ 2%

### 6.1.2 参数确定

**区间设定**（对数坐标下）：
- 下限：45000 USDT（-10%）
- 上限：60000 USDT（+20%）
- 区间比率：60000/45000 = 1.333

**比率设定**：
- ATR% = 2%
- 选择比率 = 1.02（2%）

**层数计算**：
```
层数 = log(1.333) / log(1.02) + 1 ≈ 15 层
```

**资金分配**（假设总资金 50000 USDT）：
- 单层基础数量：0.001 BTC
- 第 1 层资金：0.001 × 45000 = 45 USDT
- 第 15 层资金：0.001 × 60000 = 60 USDT

### 6.1.3 策略评估

**优势**：
- 适应百分比波动
- 适合长期持有
- 风险分散良好

**风险**：
- 上涨时资金需求增加
- 需要持续监控

## 6.2 案例二：高波动小币种

### 6.2.1 市场特征

**特点**：
- 波动率：ATR% ≈ 5%
- 价格：50 USDT
- 波动剧烈

### 6.2.2 参数设定

**比率选择**：
- 由于波动大，选择比率 = 1.04（4%）

**区间设定**：
- 下限：45 USDT
- 上限：60 USDT
- 区间比率：1.333

**层数**：
```
层数 = log(1.333) / log(1.04) + 1 ≈ 8 层
```

## 6.3 常见错误

### 6.3.1 比率过小

导致交易过于频繁，手续费侵蚀利润。

### 6.3.2 区间过大

区间比率 > 30%，层数过多，资金分散。

### 6.3.3 忽略资金需求

价格上涨时资金不足，无法维持网格。

## 6.4 本章小结

实战中需要注意：
- 根据波动率选择比率
- 合理设定区间
- 预留资金空间
- 持续监控调整
