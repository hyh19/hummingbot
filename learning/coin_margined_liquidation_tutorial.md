# 币本位合约强平价格计算教程

本文聚焦 BTCUSD 等币本位永续合约，通过统一的符号体系推导多空仓位的强平价格，并用实算示例展示不同保证金水平对风险区间的影响。

## 强平价格的意义

强制平仓价格（Liquidation Price）是指当账户权益下降至维持保证金要求时，交易所为防止账户余额为负而自动平掉仓位的价格。对于使用杠杆的币本位合约，如果行情向不利方向波动，保证金会以合约标的计价资产（例如 BTC）计入未实现亏损。一旦权益不足以覆盖维持保证金，系统就会触发强平，通常伴随手续费与额外滑点，因此提前理解并计算强平水平是风险管理的第一步。理解该价位后，才能反推所需的初始保证金、杠杆倍数与止损区间。

## 计算所需的关键参数

在币本位合约中，多头与空头共享同一套计价变量，为方便横向比较，以下符号在全文保持一致：

- 开仓价格 `P₀`：本例为 100000 美元。
- 持仓数量 `Q`：以 BTC 计的仓位，本例为 2 BTC。
- 初始保证金 `IM`：以 BTC 计的抵押物。
- 维持保证金率 `mmr`：由交易所在不同仓位档位给出。主流平台针对 2 BTC、2 倍杠杆的 BTCUSD 合约通常给出约 0.65%。
- 标记价格 `P`：用于判定盈亏与强平的实时价格。

明确上述符号后，可将多头与空头的推导步骤分别拆解，确保逻辑上互不冲突。

## 多头仓位强平公式推导

多头在价格下跌时产生亏损，可按以下步骤求得触发价格：

1. **未实现盈亏（以 BTC 计）**  
   币本位合约中，损益先以 USD 计算，再除以标记价换算成 BTC：  
   `UPL = Q × (P₀ - P) / P`

2. **账户权益（以 BTC 计）**  
   `Equity = IM - UPL = IM - Q × (P₀ - P) / P`

3. **维持保证金（以 BTC 计）**  
   `MM = Q × mmr`

4. **强平触发条件**  
   当 `Equity = MM` 时触发强平：  
   `IM - Q × (P₀ - Pₗ)/Pₗ = Q × mmr`

5. **整理得到强平价格公式**  
   `Pₗ = (P₀ × Q) / (Q + IM - Q × mmr)`

   直观理解：分子是仓位名义价值，分母是“可抗风险的 BTC 数量”（仓位数量 + 初始保证金 − 维持保证金）。若追加保证金或减少持仓，分母变大，强平价自然远离当前价格。

## 空头仓位强平公式推导

做空时，价格上涨会带来亏损，推导步骤与多头类似，但 `UPL` 的符号相反：

1. **未实现盈亏（以 BTC 计）**  
   `UPL = Q × (P - P₀) / P`

2. **账户权益（以 BTC 计）**  
   `Equity = IM - Q × (P - P₀) / P`

3. **维持保证金（以 BTC 计）**  
   `MM = Q × mmr`

4. **强平触发条件**  
   `IM - Q × (P - Pₗ)/Pₗ = Q × mmr`

5. **整理得到强平价格公式**  
   `Pₗ = (P₀ × Q) / (Q - IM + Q × mmr)`

   该表达式表明，当价格上涨至 `Pₗ` 时，空头亏损会吞噬抵押物，只剩下维持保证金。注意分母需大于 0，即 `IM < Q × (1 + mmr)`，否则表示保证金充足到足以覆盖对应档位的全部空头风险；此时强平价趋向极端高值。

## BTCUSD 示例计算

以下示例使用 `mmr = 0.65%`，即 `mmr = 0.0065`，并忽略交易所加收的强平手续费与保险基金扣减，便于聚焦核心数学关系。若使用其他品种或杠杆，只需替换相应的参数即可复现相同推导。

### 示例一｜做多：价格下行触发强平

- 输入：`Q = 2`、`P₀ = 100000`、`IM = 1`、`mmr = 0.0065`
- 计算：  
  `MM = 2 × 0.0065 = 0.013 BTC`  
  `Pₗ = (100000 × 2) / (2 + 1 - 0.013) ≈ 66933.3`

解释：当价格从 100000 美元下跌到约 66933.3 美元时，未实现亏损约为 0.987 BTC，权益被压缩到维持保证金 0.013 BTC，从而触发多头强平。初始保证金仅 1 BTC，能够吸收的下跌有限，因此触发价仍贴近开仓价，杠杆越高风险越快显现。

### 示例二｜做多：IM = Q 仍会强平

- 输入：`Q = 2`、`P₀ = 100000`、`IM = 2`、`mmr = 0.0065`
- 计算：  
  `MM = 0.013 BTC`（维持保证金不随初始保证金变化，只与持仓档位相关）  
  `Pₗ = (100000 × 2) / (2 + 2 - 0.013) ≈ 50200`

解释：当价格进一步下探到约 50200 美元时，损失同样吃掉 1.987 BTC，只剩 0.013 BTC 维持保证金，触发多头强平。虽然 IM 提升到 2 BTC，亏损缓冲更充足，但强平价仍在下方有限区间，说明“IM = Q” 并不意味着绝对安全。

> **重点提示｜IM = Q 仍可能被强平**  
>
> - `IM = Q = 2 BTC` 只意味着名义价值被暂时覆盖，价格下跌时损失仍按 USD 计价并折算成 BTC，权益缩减速度不会变慢。  
> - 强平时权益依旧等于 `MM = Q × mmr`，因此强平价 `Pₗ` 仍有限，本例大约为 50200。  
> - 只有当追加保证金远超过仓位或转换为空头让分母逼近零时，强平价才会远离当前价格，评估安全区间需同时关注 `mmr` 与分母 `Q + IM - Q × mmr`。

### 示例三｜做空：价格上行触发强平

- 输入：`Q = 2`、`P₀ = 100000`、`IM = 1`、`mmr = 0.0065`
- 计算：  
  `MM = 2 × 0.0065 = 0.013 BTC`  
  `Pₗ = (100000 × 2) / (2 - 1 + 0.013) ≈ 197247.3`

解释：当价格从 100000 美元上行到约 197247.3 美元时，空头亏损约 0.987 BTC，权益同样缩至 0.013 BTC 的维持保证金，触发做空强平。若想把触发价推得更远，需要增加初始保证金或降低仓位杠杆，让分母 `Q - IM + Q × mmr` 更大。

### 示例四｜做空：分母逼近零的极端价位

- 输入：`Q = 2`、`P₀ = 100000`、`IM = 2`、`mmr = 0.0065`
- 计算：  
  `MM = 2 × 0.0065 = 0.013 BTC`  
  `Pₗ = (100000 × 2) / (2 - 2 + 0.013) ≈ 15384615.4`

解释：在同样的参数下，价格理论上要飙升到约 15384615.4 美元，亏损才会吃光权益并触发空头强平，原因是分母 `Q - IM + Q × mmr` 接近 0，使得强平价呈指数上升。继续增加 IM 或降低 `mmr` 会让分母转负，交易所通常认定保证金过剩，不会再给出可实现的强平价。

> **重点提示｜空头分母逼近零的含义**  
>
> - 分母 `Q - IM + Q × mmr` 越小，说明保证金对空头风险的覆盖越充分，强平价会迅速偏离可成交区间。  
> - 一旦分母转负，平台往往视为保证金过剩而取消强平，但仍需警惕 `mmr` 分级调整可能把分母拉回正值。  
> - 即使强平风险极低，也要关注资金费率、自动减仓等成本，避免“没有可实现强平价”被额外费用侵蚀。

## 风险控制建议

- **动态关注 mmr**：不同交易所、不同仓位档位的维持保证金率会分级调整，持仓扩大或杠杆提升后应重新计算 `mmr`，否则强平价会被低估。
- **留出缓冲**：强平前往往还有强减仓或额外手续费，实务中应保证权益远高于 `MM`，可以通过追加保证金或降低杠杆实现。
- **重视价格基准**：强平判断多以标记价而非最新成交价为准，合理设置风险控制（如止损）应围绕标记价波动区间。
- **考虑多仓成本**：资金费率、交易手续费和自动减仓机制都会影响真实可承受的亏损幅度，必要时在公式中加上这些成本。
- **兼顾空头情景**：空头受价格上涨威胁，若市场波动剧烈，可以预设止损或对冲多头头寸，防止强平与自动减仓叠加造成额外损失。

综上，掌握参数定义、推导过程与示例计算后，即可随时根据持仓规模快速估算强平水平，并将风险控制措施前置到更安全的位置。
