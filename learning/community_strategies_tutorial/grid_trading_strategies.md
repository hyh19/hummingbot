# 网格交易策略（Grid Trading Strategies）

## 概述

网格交易策略在预设的价格区间内设置多层买卖订单，通过价格在网格间的波动来回交易获利。这类策略适合震荡市场，在价格波动但不出现明显趋势的情况下能够持续盈利。

本文档介绍社区贡献的网格交易策略实现。

## 策略详解

### fixed_grid.py

**核心功能**：固定网格交易策略。在预设的价格区间内设置多层买卖订单，通过价格波动在网格间来回交易获利。

**适用场景**：适用于震荡市场，价格在一定区间内波动时可以持续盈利。不适合单边趋势市场。

**关键特点**：

- 支持价格区间、网格层数、订单金额的自定义配置
- 包含自动再平衡功能
- 支持等距网格和几何网格（通过 `spread_scale_factor` 调整）
- 支持订单金额缩放（通过 `amount_scale_factor` 调整）

## 策略原理

### 网格结构

网格策略在价格区间 [floor, ceiling] 内分布 N 层订单：

```text
Price Ceiling (最高价)  ---|  卖单 8
                           |  卖单 7
                           |  卖单 6
                           |  卖单 5
Current Price (当前价)  ---|  当前层级
                           |  买单 4
                           |  买单 3
                           |  买单 2
Price Floor (最低价)    ---|  买单 1
```

### 交易逻辑

1. **初始化**：
   - 确定当前价格所在网格层级
   - 在当前层级下方放置买单
   - 在当前层级上方放置卖单

2. **买单成交**：
   - 当前层级下移一层
   - 在新的当前层级上方增加一个卖单

3. **卖单成交**：
   - 当前层级上移一层
   - 在新的当前层级下方增加一个买单

4. **持续交易**：
   - 价格在网格间波动，订单不断成交
   - 每次成交都能获得一个网格间距的利润

## 配置参数

### 基本参数

```python
trading_pair = "ENJ-USDT"        # 交易对
exchange = "ascend_ex"            # 交易所
n_levels = 8                      # 网格层数
grid_price_ceiling = 0.33         # 价格上限
grid_price_floor = 0.3            # 价格下限
order_amount = 18.0               # 每层订单金额
```

### 高级参数

```python
spread_scale_factor = 1.0         # 价差缩放因子（1.0 = 等距网格）
amount_scale_factor = 1.0         # 订单量缩放因子（1.0 = 等量网格）
rebalance_order_type = "limit"   # 再平衡订单类型
rebalance_order_spread = 0.02     # 再平衡订单价差
rebalance_order_refresh_time = 60 # 再平衡订单刷新时间
```

## 网格类型

### 1. 等距网格（Arithmetic Grid）

`spread_scale_factor = 1.0`

各层之间的价格间距相等：

```text
层级 8: 0.330 USDT  (spacing = 0.010)
层级 7: 0.320 USDT  (spacing = 0.010)
层级 6: 0.310 USDT  (spacing = 0.010)
层级 5: 0.300 USDT
```

**适用场景**：价格波动幅度相对固定的市场

### 2. 几何网格（Geometric Grid）

`spread_scale_factor > 1.0`

各层之间的价格间距递增：

```text
层级 8: 0.330 USDT  (spacing = 0.015)
层级 7: 0.315 USDT  (spacing = 0.012)
层级 6: 0.303 USDT  (spacing = 0.009)
层级 5: 0.294 USDT
```

**适用场景**：价格波动幅度随价格变化的市场

### 3. 订单量调整

`amount_scale_factor` 允许调整不同层级的订单量：

- `= 1.0`：所有层级订单量相等
- `> 1.0`：远离中间价的订单量更大
- `< 1.0`：靠近中间价的订单量更大

## 再平衡机制

当账户余额不足以支持当前网格配置时，策略会自动尝试再平衡：

### 再平衡逻辑

1. **检测余额不足**：
   - 基础资产不足：需要买入
   - 计价资产不足：需要卖出

2. **执行再平衡**：
   - 放置再平衡订单（买入或卖出）
   - 等待订单成交

3. **恢复网格**：
   - 余额充足后，恢复正常网格交易

### 再平衡参数

- `rebalance_order_type`：使用限价单或市价单
- `rebalance_order_spread`：限价单的价差
- `rebalance_order_refresh_time`：订单刷新间隔

## 使用建议

### 参数设置

1. **价格区间**：
   - 基于历史价格范围设置
   - 避免价格突破区间（会导致网格失效）
   - 建议覆盖近期 80-90% 的价格范围

2. **网格层数**：
   - 层数太少：单次利润高但成交频率低
   - 层数太多：成交频繁但单次利润低
   - 建议：6-10 层

3. **订单金额**：
   - 根据总资金量和网格层数设置
   - 确保所有层级的订单总量不超过可用资金
   - 建议：总资金的 10-20% / 网格层数

### 市场选择

1. **波动性**：
   - 需要适度波动（过高或过低都不理想）
   - 建议日波动率 2-5%

2. **流动性**：
   - 选择流动性好的交易对
   - 确保订单能够快速成交

3. **趋势性**：
   - 避免强趋势市场
   - 最适合横盘震荡市场

### 风险管理

1. **价格突破**：
   - 设置价格警报
   - 价格突破区间时考虑停止策略

2. **库存风险**：
   - 价格持续下跌会累积基础资产
   - 价格持续上涨会卖出所有基础资产
   - 建议：不要在强趋势市场使用

3. **再平衡失败**：
   - 确保有足够资金进行再平衡
   - 监控再平衡执行情况

### 监控要点

1. **当前网格层级**：监控价格在哪个层级
2. **余额状况**：确保资产配置合理
3. **成交频率**：评估策略活跃度
4. **累计盈亏**：追踪策略表现

## 盈利计算

### 单次交易利润

```text
网格间距 = (ceiling - floor) / (n_levels - 1)
单次利润 = 订单金额 * 网格间距 / 平均价格
单次利润率 = 网格间距 / 平均价格
```

### 示例

```python
价格上限 = 0.33 USDT
价格下限 = 0.30 USDT
网格层数 = 8
订单金额 = 18 ENJ

网格间距 = (0.33 - 0.30) / 7 ≈ 0.0043 USDT
平均价格 = 0.315 USDT
单次利润率 = 0.0043 / 0.315 ≈ 1.36%

如果每天价格往返 3 次：
日利润率 = 1.36% * 3 * 2 = 8.16%
```

## 优化技巧

1. **动态调整区间**：根据市场波动定期调整价格区间
2. **非对称网格**：在预期价格偏向的一侧设置更多层级
3. **多网格组合**：在不同价格区间运行多个网格
4. **结合趋势判断**：在趋势明确时暂停网格
