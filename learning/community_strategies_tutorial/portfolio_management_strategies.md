# 投资组合策略（Portfolio Management Strategies）

## 概述

投资组合策略通过分散投资多个资产来降低风险，同时保持稳定的收益。这类策略基于现代投资组合理论，通过资产配置和定期再平衡来维护预定的投资组合结构。

本文档介绍社区贡献的投资组合管理策略。

## 策略详解

### 1overN_portfolio.py

**核心功能**：1/N 投资组合策略，自动维护多个加密货币的等权重投资组合。定期检查各资产比例，当偏离 1/N 时进行再平衡交易。

**适用场景**：适用于希望分散投资多个加密货币的场景，提供简单但有效的资产配置方案。

**关键逻辑**：计算每个资产占总价值的百分比，自动卖出超配资产并买入低配资产。

## 策略原理

### 1/N 投资组合理论

1/N 策略是最简单的资产配置方法，将资金平均分配给 N 个资产：

```text
每个资产的目标权重 = 1 / N = 100% / N
```

**理论基础**：

- 分散化：通过投资多个资产降低非系统性风险
- 简单性：不需要复杂的模型和预测
- 稳健性：学术研究表明 1/N 策略在很多场景下表现不错

### 再平衡机制

随着市场价格变化，各资产的实际权重会偏离目标权重：

```text
实际权重 = 资产当前价值 / 投资组合总价值

偏离度 = 实际权重 - 目标权重
```

当偏离度超过阈值时，执行再平衡交易。

## 策略流程

### 1. 计算当前权重

```text
对每个资产：
  1. 获取当前余额
  2. 获取当前价格
  3. 计算资产价值（余额 * 价格）

投资组合总价值 = ∑ 所有资产价值
每个资产权重 = 资产价值 / 总价值
```

### 2. 计算偏离度

```text
目标权重 = 1 / N
偏离度 = 实际权重 - 目标权重

示例（N = 10）：
- BTC 实际权重 = 15%，目标权重 = 10%，偏离度 = +5%
- ETH 实际权重 = 8%，目标权重 = 10%，偏离度 = -2%
```

### 3. 生成交易订单

按偏离度从小到大排序：

```text
1. 卖出超配资产（偏离度 > 0）
2. 买入低配资产（偏离度 < 0）
```

策略会按顺序执行交易，优先处理偏离最严重的资产。

### 4. 执行交易

```text
对每个资产（按偏离度排序）：
  if 偏离度 < 0（低配）:
    买入金额 = |偏离度| * 总价值
    执行买单
  elif 偏离度 > 0（超配）:
    卖出金额 = 偏离度 * 总价值
    执行卖单
```

**交易过滤**：

- 忽略价值 < 1 美元的交易（避免过小的调整）
- 等待所有活跃订单完成后再开始新一轮
- 使用市价单确保快速执行

## 使用建议

### 资产选择

1. **数量**：
   - 5-15 个资产为宜
   - 太少：分散化不足
   - 太多：管理复杂，交易成本高

2. **选择标准**：
   - 市值较大、流动性好
   - 低相关性（不要选择高度相关的资产）
   - 基本面良好

3. **示例组合**：
   - 保守型：BTC (40%), ETH (40%), BNB (20%)
   - 平衡型：前 10 大市值币种等权重
   - 激进型：包含部分中小市值币种

### 再平衡频率

**建议设置**：

- 检查频率：每小时或每几小时
- 实际交易：仅当偏离度 > 阈值时
- 最小交易金额：> 1 美元（避免频繁小额交易）

**考虑因素**：

1. **交易费用**：频繁再平衡会产生较高费用
2. **市场波动**：波动大时需要更频繁再平衡
3. **滑点**：大额交易可能产生滑点

### 初始资金分配

**方法 A - 手动分配**：

在策略运行前，手动买入各资产使其接近 1/N 配置

**方法 B - 自动分配**：

启动策略时持有全部 USDT，让策略自动买入各资产

**建议**：方法 A 可以减少初始交易成本

### 风险管理

1. **单一资产风险**：
   - 某个资产大幅下跌会拖累整体表现
   - 定期审查资产列表，剔除表现差的资产

2. **市场风险**：
   - 整体市场下跌时，所有资产都会受影响
   - 考虑加入稳定币或对冲仓位

3. **再平衡风险**：
   - 卖高买低是再平衡的本质
   - 但在趋势市场中可能卖掉表现好的资产

## 性能评估

### 关键指标

1. **总收益率**：

   ```text
   收益率 = (当前总价值 - 初始总价值) / 初始总价值
   ```

2. **夏普比率**：

   ```text
   夏普比率 = (平均收益率 - 无风险利率) / 收益率标准差
   ```

3. **最大回撤**：

   ```text
   最大回撤 = (峰值 - 谷值) / 峰值
   ```

### 对比基准

- 持有 BTC 不动
- 市值加权的加密货币指数
- 传统 1/N 策略的历史表现

## 进阶优化

### 1. 动态权重

根据市场情况调整权重，而非固定 1/N：

- 风险平价：根据资产波动率调整权重
- 动量加权：表现好的资产增加权重
- 最小方差：优化权重以降低组合波动

### 2. 条件再平衡

仅在特定条件下再平衡：

- 偏离度阈值：> 5% 才触发
- 时间阈值：至少间隔 1 天
- 成本效益：预期收益 > 交易成本

### 3. 分批再平衡

不是一次性完全再平衡，而是逐步调整：

- 每次只调整偏离度的 50%
- 减少市场冲击
- 降低在错误时机全仓调整的风险

## 实践案例

### 案例 1：保守型组合

```python
base_currencies = ["BTC", "ETH", "BNB"]
quote_currency = "USDT"
```

- 仅投资头部资产
- 风险较低，收益相对稳定
- 适合新手和风险厌恶者

### 案例 2：平衡型组合

```python
base_currencies = [
    "BTC", "ETH", "BNB", "ADA", "DOT", 
    "SOL", "AVAX", "MATIC", "LINK", "UNI"
]
```

- 分散投资前 10 大币种
- 平衡风险和收益
- 适合大多数投资者

### 案例 3：主题型组合

```python
# DeFi 主题
base_currencies = ["UNI", "AAVE", "MKR", "COMP", "SNX"]

# Layer 2 主题
base_currencies = ["MATIC", "ARB", "OP", "IMX", "LRC"]
```

- 专注特定领域
- 高风险高收益
- 需要对该领域有深入了解
