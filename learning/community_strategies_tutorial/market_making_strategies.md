# 做市策略（Market Making Strategies）

## 概述

做市策略通过在买卖两侧提供流动性来赚取价差收益。做市商在市场中同时挂买单和卖单，当两边的订单都成交时，可以获得买卖价差带来的利润。这类策略适合流动性较好且波动适中的市场。

本文档介绍 3 个社区贡献的做市策略，从简单的固定价差做市到使用技术指标动态调整参数的高级做市策略。

## 策略列表

### 1. simple_pmm_no_config.py

**核心功能**：简化版纯做市策略，无需配置文件即可运行。在指定交易对的买卖两侧按设定价差放置限价订单，并定期刷新订单。

**适用场景**：适合初学者学习做市策略的基本原理，也可用于流动性较好的市场进行简单做市。

**关键参数**：

- `bid_spread`（买单价差）：买单相对参考价格的价差百分比
- `ask_spread`（卖单价差）：卖单相对参考价格的价差百分比
- `order_refresh_time`（订单刷新时间）：订单定期刷新的时间间隔（秒）
- `order_amount`：每个订单的下单量
- `price_source`：参考价格来源（中间价或最新成交价）

**策略逻辑**：

1. 获取市场参考价格（中间价或最新成交价）
2. 根据买卖价差计算买单和卖单价格
3. 放置限价订单
4. 到达刷新时间后，取消所有订单并重新放置

**使用建议**：

- 初始价差设置建议在 0.1% - 0.5% 之间
- 订单刷新时间不宜过短，避免频繁取消订单产生过多费用
- 确保有足够的基础资产和计价资产余额
- 建议在流动性好、波动率适中的交易对上使用

### 2. adjusted_mid_price.py

**核心功能**：基于调整后中间价的做市策略。通过模拟一定数量的买卖订单来计算调整后的中间价，然后在该价格基础上放置做市订单。

**适用场景**：适用于订单簿深度不均匀的市场，通过调整中间价来更准确地反映市场真实供需关系。

**关键特点**：

- 使用 `test_volume` 参数计算假设性订单的平均成交价格
- 调整后的中间价更能反映大额订单的真实成交价格
- 适合订单簿一侧深度明显大于另一侧的市场

**策略逻辑**：

1. 模拟执行 `test_volume` 数量的买入和卖出
2. 计算这两个假设订单的平均成交价格
3. 以这两个平均价格的中点作为调整后中间价
4. 在调整后中间价基础上应用价差放置订单

**配置参数**：

- `test_volume`：用于计算调整价格的假设订单量
- `bid_spread`、`ask_spread`：相对调整后中间价的价差
- `amount`：实际下单量
- `order_refresh_time`：订单刷新时间

**使用建议**：

- `test_volume` 应设置为实际交易量的 5-10 倍，以准确反映市场深度
- 适合单边深度较大的市场，可以获得更合理的参考价格
- 监控调整前后中间价的差异，评估策略效果

### 3. pmm_with_shifted_mid_dynamic_spreads.py

**核心功能**：结合 RSI 指标动态调整中间价，并使用 NATR 指标动态调整价差的高级做市策略。根据市场波动率和超买超卖状态自动优化订单位置。

**适用场景**：适用于波动较大的市场，能够根据市场状态动态调整策略参数，提高盈利能力和风险控制。

**关键指标**：

- **RSI（相对强弱指标）**：用于判断市场超买超卖状态，动态调整中间价偏移
  - RSI > 50：市场偏多，向下偏移中间价
  - RSI < 50：市场偏空，向上偏移中间价
  - 最大偏移幅度 = NATR 值

- **NATR（标准化真实波动幅度）**：用于根据市场波动率动态调整价差
  - 波动率高时，增大价差以保护利润
  - 波动率低时，减小价差以提高成交概率
  - 公式：`spread_multiplier = NATR / spread_base`

**策略逻辑**：

1. 获取最新 K 线数据并计算 RSI 和 NATR 指标
2. 根据 RSI 计算价格偏移系数
3. 根据 NATR 计算价差调整系数
4. 应用调整后的参考价格和价差放置订单
5. 定期刷新订单并重新计算指标

**配置参数**：

- `spread_base`：基础价差（默认 0.008 即 0.8%）
- `order_refresh_time`：订单刷新时间
- `order_amount`：订单数量
- K 线周期：默认使用 3 分钟 K 线

**使用建议**：

- 适合波动率较高的市场，可以根据市场状态自适应调整
- `spread_base` 应根据历史 NATR 的平均值设置
- 监控 RSI 和 NATR 指标的变化，评估策略表现
- 建议先在纸盘模式下测试，观察指标调整效果

**统计信息**：策略会记录买卖订单数量和成交量，便于分析策略表现。

## 做市策略通用注意事项

### 风险管理

1. **库存风险**：做市会导致持仓不平衡，需要定期平衡或对冲
2. **价格风险**：市场快速单边行情可能导致损失
3. **交易费用**：频繁交易会产生较高的交易费用，需要确保价差足够覆盖费用

### 性能优化

1. **价差设置**：价差太小成交频繁但利润低，价差太大利润高但成交少
2. **订单刷新频率**：太频繁会增加费用，太慢会错过市场机会
3. **订单量设置**：根据市场流动性和自身资金规模合理设置

### 市场选择

1. **流动性**：选择流动性好的交易对，确保订单能够成交
2. **波动性**：适度波动的市场最适合做市，过高或过低都不理想
3. **交易费用**：考虑交易所的手续费率，Maker 费用低的交易所更适合
