# 方向性交易策略（Directional Trading Strategies）

## 概述

方向性交易策略通过预测市场价格走势方向来获利。这类策略通常使用技术指标识别入场和出场时机，适合有明确趋势或周期性波动的市场。方向性策略相比做市策略风险较高，但潜在收益也更大。

本文档介绍 9 个社区贡献的方向性交易策略，涵盖从简单的单指标策略到复杂的多指标多时间周期策略。

## 策略列表

### 1. simple_rsi_no_config.py

**核心功能**：基于 RSI 指标的简单方向性交易策略。当 RSI 超过 70 时做空，低于 30 时做多，使用 PositionExecutor 管理仓位。

**适用场景**：适用于震荡市场，通过捕捉超买超卖机会获利。适合初学者学习基于技术指标的方向性策略。

**关键参数**：

- RSI 长度：7（快速 RSI，更敏感）
- 做多信号：RSI < 30
- 做空信号：RSI > 70
- 支持止损、止盈和追踪止损功能

**策略特点**：

- 基于 `DirectionalStrategyBase` 实现，提供完整的仓位管理
- 自动风险控制（止损、止盈、时间限制）
- 支持杠杆交易

### 2. directional_strategy_rsi_spot.py

**核心功能**：专为现货市场设计的 RSI 方向性策略，与上一个策略类似但针对现货交易优化。

**适用场景**：适用于现货市场的方向性交易，通过 RSI 指标识别超买超卖状态。

**关键特点**：

- 基于 `DirectionalStrategyBase` 实现
- 完整的仓位管理和风控功能
- 针对现货市场的特点进行优化

**配置参数**：

- 交易对：ETH-USDT
- 交易所：binance（现货）
- RSI 长度：7
- K 线周期：3 分钟

### 3. directional_strategy_macd_bb.py

**核心功能**：结合 MACD 和布林带指标的方向性策略。当价格在布林带下轨且 MACD 直方图转正时做多，在上轨且直方图转负时做空。

**适用场景**：适用于趋势和震荡结合的市场，通过多指标确认提高信号可靠性。

**关键指标**：

- **BBP（布林带百分比）**：价格在布林带中的相对位置
  - BBP < 0.4：接近下轨，潜在买入区域
  - BBP > 0.6：接近上轨，潜在卖出区域

- **MACD**：趋势跟随指标
  - MACD > 0：多头趋势
  - MACD < 0：空头趋势

- **MACDh（MACD 直方图）**：动量变化
  - MACDh > 0：动量转强
  - MACDh < 0：动量转弱

**交易信号**：

- 做多：BBP < 0.4 且 MACDh > 0 且 MACD < 0
- 做空：BBP > 0.6 且 MACDh < 0 且 MACD > 0

### 4. directional_strategy_bb_rsi_multi_timeframe.py

**核心功能**：多时间周期策略，结合不同时间框架的布林带和 RSI 指标生成交易信号。通过加权平均不同周期的信号值得出最终决策。

**适用场景**：适用于需要多时间框架确认的交易场景，可以过滤掉短期噪音，提高信号质量。

**关键特点**：

- 支持多个 K 线周期（默认 1 分钟和 3 分钟）
- 短期信号权重 0.7，长期信号权重 0.3
- 信号归一化处理（-1 到 1 之间）

**信号计算**：

1. 对每个时间周期计算 RSI 的 SMA 和布林带百分比
2. 将指标值归一化到 -1 到 1 范围
3. 加权合成最终信号
4. 应用阈值过滤（> 0.5 做多，< -0.5 做空）

**配置建议**：

- 可以添加更多时间周期以提高信号可靠性
- 调整权重分配以适应不同市场特征
- 阈值可根据回测结果优化

### 5. directional_strategy_trend_follower.py

**核心功能**：趋势跟踪策略，使用 SMA 21 和 SMA 200 判断趋势方向，结合布林带百分比进行过滤。在明确趋势中顺势开仓。

**适用场景**：适用于趋势明显的市场，通过跟随主要趋势获利。

**关键逻辑**：

- **趋势判断**：SMA 21 > SMA 200 为多头趋势，反之为空头趋势
- **过滤条件**：BBP 在 0.35 到 0.65 之间（避免超买超卖区域）
- **交易信号**：
  - 做多：多头趋势 + 过滤条件满足
  - 做空：空头趋势 + 过滤条件满足

**策略优势**：

- 使用长期均线确认趋势，减少假信号
- 布林带过滤避免在极端位置入场
- 适合捕捉中长期趋势行情

### 6. directional_strategy_widening_ema_bands.py

**核心功能**：基于双 EMA 带宽的策略。当短期 EMA 8 和长期 EMA 54 之间的距离百分比超过阈值时，判断为超买或超卖状态。

**适用场景**：适用于识别价格偏离均值过远的机会，进行均值回归交易。

**关键参数**：

- `distance_pct_threshold`：触发阈值（默认 2%）
- 短期 EMA：8
- 长期 EMA：54

**交易逻辑**：

1. 计算两条 EMA 之间的距离百分比
2. 距离 > 2%：价格偏离过高，做空（均值回归）
3. 距离 < -2%：价格偏离过低，做多（均值回归）

**适用市场**：

- 震荡市场效果最佳
- 避免在强趋势市场使用（可能持续偏离）

### 7. buy_low_sell_high.py

**核心功能**：简单的均线交叉策略。使用快速 MA（5 秒）和慢速 MA（20 秒）的金叉和死叉信号进行交易。

**适用场景**：适合学习均线策略的基本逻辑，也可用于高频交易场景。

**关键特点**：

- 使用 `pingpong` 变量确保买卖信号交替出现
- 避免连续同向交易
- 极短周期，适合高频场景

**交易信号**：

- 金叉（快线上穿慢线）：买入
- 死叉（快线下穿慢线）：卖出

**注意事项**：

- 使用秒级 MA，信号频繁，交易费用较高
- 适合流动性极好的市场
- 建议增加趋势或动量过滤

### 8. buy_dip_example.py

**核心功能**：逢低买入策略。当价格低于 50 日均线 5% 以上时触发买入，通过外部数据源（Binance API）获取历史数据。

**适用场景**：适用于长期看涨但短期回调的资产，通过定投方式在低点建仓。

**关键特点**：

- 集成 RateOracle 进行 USD 汇率转换
- 支持固定美元金额下单
- 调用 Binance REST API 获取历史 K 线数据
- 包含冷却期机制，避免频繁交易

**策略逻辑**：

1. 获取过去 50 天的收盘价数据
2. 计算 50 日移动平均线
3. 如果当前价格 < MA50 * 0.95，触发买入信号
4. 使用预设美元金额计算买入数量
5. 等待冷却期后才能再次买入

**配置参数**：

- `buy_usd_amount`：每次买入的美元金额
- `moving_avg_period`：移动平均线周期（默认 50）
- `dip_percentage`：触发买入的跌幅百分比（默认 5%）
- `cool_off_interval`：冷却期时间（秒）

### 9. macd_bb_directional_strategy.py

**核心功能**：完整的 MACD + 布林带策略实现，包含详细的仓位管理、CSV 数据记录和止损止盈功能。

**适用场景**：适用于需要完整回测和性能追踪的专业交易场景。

**关键特点**：

- 自动记录每笔交易到 CSV 文件
- 动态止损止盈（基于波动率计算）
- 完整的仓位生命周期管理
- 支持多个活跃仓位

**策略逻辑**：

1. 计算 MACD、布林带和标准差指标
2. 判断入场条件：
   - 做多：BBP < 0.2 且 MACDh > 0 且 MACD < 0
   - 做空：BBP > 0.8 且 MACDh < 0 且 MACD > 0
3. 根据标准差动态设置止损止盈
4. 使用 PositionExecutor 管理仓位
5. 仓位关闭后记录数据到 CSV

**数据记录**：

- 时间戳、交易对、交易方向
- 入场价格、出场价格、盈亏百分比
- 止损、止盈、时间限制设置
- 杠杆倍数

## 方向性策略通用建议

### 风险管理

1. **止损设置**：每个仓位都应设置止损，控制单次最大损失
2. **仓位大小**：不要将所有资金投入单一仓位
3. **杠杆控制**：谨慎使用杠杆，建议从低杠杆开始

### 指标选择

1. **趋势指标**：MA、EMA、MACD（判断方向）
2. **震荡指标**：RSI、Stochastic（判断超买超卖）
3. **波动率指标**：布林带、ATR（判断市场状态）
4. **组合使用**：多个指标确认可以提高成功率

### 回测与优化

1. **历史数据回测**：使用足够长的历史数据测试策略
2. **参数优化**：寻找最优参数组合，但避免过度拟合
3. **样本外测试**：在未参与优化的数据上验证策略
4. **纸盘交易**：实盘前先用纸盘模式测试

### 市场选择

1. **流动性**：选择流动性好的交易对，确保能够及时开平仓
2. **波动性**：根据策略特点选择合适波动率的市场
3. **交易时段**：避开流动性差的时段
