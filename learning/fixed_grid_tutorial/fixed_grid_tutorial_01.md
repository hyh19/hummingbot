## 1.1 什么是 Fixed Grid 策略

Fixed Grid（固定网格）策略是一种在预设价格区间内自动执行买卖的量化交易策略。它的核心思想是：

- 在价格区间内设置多个价格层级（网格）
- 在每个网格层级预先放置限价买单和卖单
- 当价格下跌触及买单时买入，价格上涨触及卖单时卖出
- 通过价格波动在网格间来回穿梭获取差价利润

### 1.1.1 形象比喻

想象一个渔网铺在海面上：

- **网格线**：就像渔网的经纬线，代表不同的价格层级
- **价格波动**：就像海浪上下起伏，在网格间穿梭
- **捕获利润**：每当海浪穿过一个网格，就捕获一次利润

### 1.1.2 与传统交易的区别

| 维度 | 传统手动交易 | Fixed Grid 策略 |
|------|-------------|----------------|
| 交易时机 | 需要人工判断 | 自动触发执行 |
| 交易频率 | 较低，受精力限制 | 较高，24/7 运行 |
| 情绪影响 | 容易受市场情绪影响 | 严格执行预设逻辑 |
| 适用市场 | 趋势市场更佳 | 震荡市场更佳 |
| 操作难度 | 需要经验和时间 | 配置后自动运行 |

## 1.2 适用场景和市场条件

Fixed Grid 策略并非适用于所有市场情况，它有明确的适用场景。

### 1.2.1 理想市场条件

**震荡市场（横盘整理）**

- 价格在一定区间内反复波动
- 没有明显的单边趋势
- 波动幅度适中，有规律性

**示例**：某交易对在 0.30-0.35 USDT 区间内持续震荡 2-3 周。

### 1.2.2 适用的交易对特征

1. **流动性充足**
   - 订单簿深度好，滑点小
   - 日均交易量稳定
   - 买卖价差较小

2. **波动性适中**
   - 日波动率在 2%-8% 之间较为理想
   - 过低：利润空间小
   - 过高：容易突破网格区间

3. **价格区间稳定**
   - 在可预见的时间内保持区间震荡
   - 有明显的支撑位和阻力位

### 1.2.3 不适用的场景

**强势单边行情**

- 价格持续上涨或下跌
- 快速突破网格上限或下限
- **风险**：可能导致持仓全部变为基础资产或报价资产

**低流动性市场**

- 订单簿稀疏，价差大
- 订单难以成交
- **风险**：滑点高，实际收益低于预期

**高波动性市场**

- 价格剧烈波动，缺乏规律
- 频繁触及网格边界
- **风险**：频繁触发再平衡，手续费高

## 1.3 策略优势

### 1.3.1 自动化执行

- 无需盯盘，策略 24/7 自动运行
- 自动捕捉价格波动机会
- 避免人为情绪干扰

### 1.3.2 利用震荡市场

- 在其他策略难以获利的横盘市场中赚取差价
- 将市场"噪音"转化为收益来源
- 波动越频繁，套利机会越多

### 1.3.3 风险分散

- 不依赖对价格方向的判断
- 订单分布在多个价格层级
- 单次交易量小，风险分散

### 1.3.4 收益可预测

- 基于网格设置，收益相对可计算
- 每次交易的利润空间明确
- 适合稳健型投资者

### 1.3.5 灵活可调

- 支持自定义网格数量和价格区间
- 可根据市场变化调整参数
- 支持多种扩展和优化方式

## 1.4 策略风险

### 1.4.1 单边行情风险

**价格持续上涨**

- 卖单逐渐被触发，基础资产减少
- 最终可能持有大量报价资产（如 USDT），错过上涨收益
- **示例**：在 ENJ-USDT 网格中，若 ENJ 从 0.30 涨到 0.50，可能只剩 USDT

**价格持续下跌**

- 买单逐渐被触发，基础资产增加
- 最终可能持有大量基础资产，面临账面亏损
- **示例**：若 ENJ 从 0.30 跌到 0.20，可能持有大量 ENJ，总价值缩水

### 1.4.2 价格突破网格风险

**突破上限**

- 价格超出网格上限，所有卖单已成交
- 策略停止工作，需手动调整参数

**突破下限**

- 价格跌破网格下限，所有买单已成交
- 可能面临较大浮亏

### 1.4.3 资金不足风险

- 网格策略需要在多个层级同时挂单
- 需要充足的基础资产和报价资产
- 资金不足会导致策略无法正常运行

### 1.4.4 交易手续费侵蚀利润

- 高频交易会产生较多手续费
- 网格间距过小，利润可能被手续费抵消
- 需选择手续费较低的交易所

### 1.4.5 流动性风险

- 在低流动性市场，订单可能无法及时成交
- 实际成交价格可能偏离预期
- 影响策略整体效果

## 1.5 与其他策略的对比

### 1.5.1 vs 纯做市策略（PMM）

| 维度 | Fixed Grid | Pure Market Making |
|------|------------|-------------------|
| 订单分布 | 固定价格层级 | 围绕市场中间价 |
| 价格跟踪 | 不跟踪市场价 | 实时跟踪市场价 |
| 适用市场 | 震荡市场 | 任何市场 |
| 库存风险 | 较高 | 较低（有对冲） |
| 实现复杂度 | 中等 | 较高 |

### 1.5.2 vs 移动网格策略

| 维度 | Fixed Grid | Dynamic Grid |
|------|------------|--------------|
| 网格中心 | 固定不变 | 跟随价格移动 |
| 参数调整 | 需手动调整 | 自动调整 |
| 单边行情 | 风险较高 | 风险较低 |
| 震荡行情 | 表现优秀 | 表现良好 |
| 实现复杂度 | 简单 | 复杂 |

### 1.5.3 vs 趋势跟踪策略

| 维度 | Fixed Grid | Trend Following |
|------|------------|-----------------|
| 市场假设 | 价格震荡 | 价格趋势 |
| 盈利方式 | 赚取差价 | 把握趋势 |
| 震荡市场 | 优秀 | 较差（频繁止损） |
| 趋势市场 | 较差 | 优秀 |
| 交易频率 | 高 | 低至中 |

## 1.6 成功案例与收益预期

### 1.6.1 收益来源

Fixed Grid 的收益主要来自：

1. **买卖价差**：每次网格触发产生的差价利润
2. **波动套利**：价格在网格间反复穿梭产生的多次交易机会
3. **复利效应**：利润再投资，增加网格订单规模

### 1.6.2 收益率估算

在理想条件下（震荡市场，合理参数配置）：

- **保守型配置**：年化收益率 5%-15%
- **均衡型配置**：年化收益率 15%-30%
- **激进型配置**：年化收益率 30%-60%（但风险也更高）

**注意**：以上仅为理论估算，实际收益取决于多种因素：

- 市场波动性
- 网格参数设置
- 交易手续费
- 资金利用率
- 市场流动性

### 1.6.3 真实场景示例

**场景：中等波动的震荡市场**

- 交易对：ENJ-USDT
- 价格区间：0.30-0.33 USDT
- 网格层级：8 层
- 投入资金：1000 USDT
- 运行时间：30 天
- 价格在区间内波动 20 次
- 手续费率：0.1%

## 1.7 本章小结

Fixed Grid 策略是一种适用于震荡市场的自动化交易策略，通过在预设价格区间内放置多层买卖订单，捕捉价格波动产生的套利机会。

**关键要点**：

1. **最适合震荡市场**，不适合单边行情
2. **自动化执行**，无需盯盘
3. **风险可控**，但需注意价格突破网格和单边行情
4. **需要充足资金**支持多层级订单
5. **收益稳健**，适合中长期运行

在决定使用 Fixed Grid 策略之前，请确保：

- 充分理解策略原理和风险
- 选择合适的市场和交易对
- 准备足够的资金
- 有能力监控和调整策略
