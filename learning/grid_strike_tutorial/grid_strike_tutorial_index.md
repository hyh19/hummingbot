# GridStrike 策略教程系列

## 📚 教程总览

欢迎学习 Hummingbot 的 GridStrike 网格交易策略！本教程系列将带您从零开始，全面掌握 GridStrike 策略的使用和实现原理。

GridStrike 是基于 Hummingbot Strategy_v2 框架构建的现代化网格交易策略，专为期货市场设计。它采用先进的 Controller-Executor 架构，支持杠杆交易、智能风险管理和灵活的参数配置。

## 🎯 适用人群

本教程系列适合以下用户：

- **初学者**：想要了解 Strategy_v2 框架和网格交易
- **交易者**：希望在期货市场使用网格策略获利
- **开发者**：需要深入理解 Controller-Executor 模式，进行二次开发

## ⚠️ 风险提示

- **杠杆交易风险**：期货杠杆交易风险极高，可能导致本金全部损失
- **强平风险**：价格剧烈波动可能导致强制平仓
- **资金费率**：持仓需要支付或收取资金费率，影响实际收益
- **市场风险**：单边行情可能导致策略失效或重大亏损
- **技术风险**：网络故障、交易所问题等可能影响策略运行

**重要提醒**：

- 本教程仅供学习参考，不构成投资建议
- 使用策略前请充分了解风险，谨慎决策
- 建议先在测试网络或小额资金下测试策略
- 切勿使用超出承受能力的资金进行交易
