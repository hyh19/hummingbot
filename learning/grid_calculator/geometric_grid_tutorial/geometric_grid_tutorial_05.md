## 5.1 等比网格的资金分配特点

### 5.1.1 高价区资金需求

在等比网格中，高价层级需要更多资金：

```
如果每层投入相同数量（如 0.1 BTC）：
第 1 层（50000）：0.1 × 50000 = 5000 USDT
第 10 层（60950）：0.1 × 60950 = 6095 USDT

总资金需求随价格上涨而增加
```

### 5.1.2 资金分配策略

**策略一：等数量分配**

每层投入相同的基础资产数量：

- 优点：简单直观
- 缺点：资金需求不均衡

**策略二：等价值分配**

每层投入相同的 USDT 价值：

- 优点：资金需求均衡
- 缺点：基础资产数量递减

**策略三：加权分配**

低价区多投，高价区少投：

- 优点：资金利用更高效
- 缺点：计算复杂

## 5.2 层数计算公式

### 5.2.1 基于比率

```
层数 = log(上限/下限) / log(比率) + 1

例如：
上限：60000
下限：50000
比率：1.02

层数 = log(60000/50000) / log(1.02) + 1
    = log(1.2) / log(1.02) + 1
    ≈ 10.2 ≈ 11 层
```

### 5.2.2 基于百分比区间

```
如果已知区间百分比 P：
层数 ≈ P / 比率百分比 + 1

例如：
区间：20%
比率：2%

层数 ≈ 20% / 2% + 1 = 11 层
```

## 5.3 资金管理建议

### 5.3.1 最小资金要求

考虑到高价区需求：

```
建议总资金 = 单层资金 × 层数 × 安全系数

安全系数：1.2-1.5（预留上涨空间）
```

### 5.3.2 最优层数

平衡资金和分散：

- 最小：5 层
- 标准：10-15 层
- 最大：20-25 层（根据资金）

## 5.4 本章小结

等比网格的资金分配需要特别注意：

- 高价区资金需求更大
- 层数计算公式基于对数
- 需要预留上涨空间
